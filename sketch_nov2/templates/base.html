Connecting nRF52840 to AstroHealth
Option 1: Direct in Browser (Zero Install!)
  1. Plug your nRF52840 board via USB into this computer.
  2. In this web app (Chrome or Edge), click "Connect nRF52840" → "Connect via USB Cable (Serial)".
  3. Select your board's COM port and click Connect! Live sensor data will stream straight into your charts!
Option 2: Direct Wireless BLE in Browser
  1. Power the board (battery or USB).
  2. Click "Connect nRF52840" → "Connect via BLE (Wireless)".
  3. Pair with "AstroHealth" or "Bluefruit52".
Option 3: Python Background Bridge Script

If you prefer running a command-line bridge script:

pip install pyserial requests
python serial_bridge.py --port COM3
